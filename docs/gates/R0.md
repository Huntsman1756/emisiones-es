# R0 — PUBLIC RELEASE GATE (post-P0)

**Estado:** BLOCKED hasta cierre de P0 (`P0-E.1` → `P0-F` → tag final).
**Motivo del gate:** separar el repositorio canónico de investigación del
export público OSS. El saneamiento de GitHub **no** se mezcla con el
experimento P0.

> Terminología: el hallazgo corregido en `50bd311` es una
> **redistribution/publication-policy breach** del proyecto (los 34 PDFs y
> derivados de texto completo contradecían la política conservadora fijada
> en `docs/licensing.md`), no una afirmación de infracción jurídica: CNMV
> permite determinados usos sujetos a su nota legal.

## 1. Modelo de dos repositorios

```text
emisiones-es-canonical     PRIVATE
│
│ historial original (commits, SHAs, audit trail)
│ tags g0/g1/g2-*-final-fail, tag final P0
│ evaluation seals
│ corpus local (.work/, snapshots, p0/docs|docling|ir)
│
└── publication export (copia, nunca in-place)
        ↓
emisiones-es               PUBLIC
        historial sanitizado por git filter-repo
        sin PDFs CNMV ni Docling/IR redistribuibles
        código + manifests + resultados permitidos
```

**El repo canónico no se reescribe.** Su historial es la evidencia: los
`git_sha`/`tree_sha` embebidos en `p0/ui-freeze*.json` y
`g0/code-freeze.json` solo resuelven contra ese historial. Los seals
autoritativos son los **SHA-256 a nivel de fichero**.

## 2. Secuencia

```text
0. (experimento)  P0-E.1 gold humano → P0-F → tag estado final P0
1. backup         git bundle create emisiones-es-canonical.bundle --all
                  (privado, junto al checkout canónico; nunca se publica)
2. adapter        incorporar adaptador IR congelado al repo (§3)
3. export         git clone --no-local canonical → working copy
4. sanitize       git filter-repo --path p0/docs --path p0/docling
                  --path p0/ir --invert-paths   (SOLO en la copia)
5. provenance     docs/PUBLICATION_PROVENANCE.md en el export (§4)
6. verify         §5 checklist
7. publish        push a origin público
```
